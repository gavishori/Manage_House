# ניהול הוצאות והכנסות

דשבורד אישי להוצאות ולהכנסות של הבית: סקירה, ניהול חודשי מול תקציב, התחייבויות קבועות, תובנות, פנסיה, שאלות פתוחות ופירוט כל התנועות.

## פרטיות: חשוב

הריפו הזה ציבורי, והתיקייה `docs/` מתפרסמת לאינטרנט. לכן:

- **הקוד** (`build.py`, `template.html`) נמצא בריפו, ואין בו אף נתון אישי.
- **הנתונים, ההגדרות האישיות והדף שנבנה** נשמרים ב-`finance/private/`. התיקייה מוחרגת ב-`.gitignore`, ולכן לא עולה לגיטהאב ולא מתפרסמת.

לעולם לא להעביר קבצים מ-`finance/private/` ל-`docs/`, ולא להסיר את השורה מ-`.gitignore`.

## מבנה

```
finance/
  build.py           בונה את הדשבורד מכל הקבצים בתיקייה raw
  template.html      תבנית הדף (בלי נתונים)
  private/           לא נכנס ל-git
    raw/             כאן שמים את קבצי הייצוא
    config.json      כללי סיווג, תקציב, תובנות ושאלות
    dashboard.html   הדף שנבנה, פותחים אותו בדפדפן
```

## עדכון חודשי

1. מורידים קבצים חדשים ושמים אותם ב-`finance/private/raw/`:
   - **הבנק**: ייצוא תנועות עו״ש ל-Excel (`.xls`)
   - **מקס**: ייצוא עסקאות לכל הכרטיסים (`.xlsx`)
   - **bit**: ייצוא היסטוריה (`.csv`)
   - **תלושי פנסיה**: קבצי PDF
   
   אין צורך למחוק קבצים ישנים. כפילויות בין קבצים שחופפים בתאריכים מזוהות ונספרות פעם אחת.
2. מריצים:
   ```
   python finance/build.py
   ```
   (בפעם הראשונה: `pip install xlrd openpyxl pdfplumber`)
3. פותחים את `finance/private/dashboard.html` בדפדפן.

## הגדרות (`private/config.json`)

- `categories`: כל קטגוריה וסוגה. `income` / `expense` נספרות במאזן החודשי. `income_oneoff` / `expense_oneoff` (חד-פעמי) ו-`pass` (כסף שרק עובר דרככם) מוצגות בנפרד. ל-`budget` יש תקציב חודשי מומלץ.
- `bank_rules` ו-`card_rules`: כללי סיווג לפי ביטוי רגולרי על תיאור התנועה. הכלל הראשון שמתאים קובע. `@card` מסמן את החיוב הכולל של מקס בבנק: הוא מוחלף בפירוט מקובץ מקס, אם הקובץ מכסה את אותו תאריך.
- `forecast`: הסכומים הקבועים לתחזית של חודש רגיל, למשל שכירות וליסינג.
- `fixed_commitments`, `insights`, `learned`, `questions`: הטקסטים שבלשוניות.

תקציב שמשנים בדף, ותשובות לשאלות, נשמרים בדפדפן. כדי לעדכן את ההגדרות עצמן, מעתיקים את התשובות מהדף ומעדכנים את `config.json`, או מדביקים אותן ל-Claude.
